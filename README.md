Entry for make.fun "The Internet in One Word" — one word to sum up the whole internet. Mine is **Brainrot**: the internet is an endless feed built to melt attention into mush, and the word is the joke and the diagnosis at once. It is funny on its own, true of the whole internet rather than one app, surprising enough that it is not the first word anyone reaches for, and short enough to land in a single beat.

> Brainrot

## Run it

```sh
node main.ts
```

This writes the word to `/output/entry.txt` and prints it.
